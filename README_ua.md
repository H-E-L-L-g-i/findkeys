# FindKeys aka Keyhound



FindKeys (Keyhound) — легка кросплатформенна CLI-утиліта на Python, яка сканує систему  

на наявність SSH і GPG ключів, збирає їх та копіює у вказане користувачем місце для   

зручного резервного копіювання чи перенесення.

Для ефективного пошуку утиліта використовує мультипотоковість, що дозволяє одночасно   

перевіряти кілька директорій і пришвидшує процес. Знайдені ключі автоматично   

архівуються у ZIP.

Працює на Windows, macOS і Linux.

У майбутніх версіях буде підтримка інших форматів архівів і додаткових функцій.
