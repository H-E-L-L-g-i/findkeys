# FindKeys aka Keyhound


FindKeys(Keyhound) is a lightweight, cross-platform CLI tool written in Python   

that searches your system for all existing SSH and GPG keys, collects them,  

and copies to a user-specified location for easy backup or migration.    

It automatically creates a compressed archive (currently ZIP format) containing    

all found keys — perfect for safely transferring your keys to a new device or  

sharing with trusted services.

Supports Windows, macOS, and Linux.  

Future releases will support additional archive formats and advanced features.
