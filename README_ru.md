# FindKeys aka Keyhound


FindKeys (Keyhound) — лёгкая кроссплатформенная CLI-утилита на Python,   

которая ищет все SSH и GPG ключи в системе, собирает их и копирует в выбранную  

пользователем папку для удобного резервного копирования или переноса.

Для повышения скорости поиска применяется мультитрединг, позволяющий параллельно   

обходить несколько директорий без блокировки основного потока.  

Все найденные ключи автоматически архивируются в ZIP.

Работает на Windows, macOS и Linux.

В будущих версиях будет добавлена поддержка других форматов архивов и   

новых возможностей.
